# CCP Roadmap

## Overview

This roadmap describes the planned evolution of the CCP (Cost Control Platform) project.

The platform is being developed as a modern financial management SaaS focused on:

* personal finance
* vehicle financial management
* financial automation
* analytics
* scalability
